# Evaluation Dataset and Methodology

This directory contains the end-to-end evaluation tools for the Mechanical Datasheet Extraction pipeline. 

## Structure
- `ground_truth/`: Contains manually verified `.json` files mapping to PDF documents. 
- `fixtures/`: Test edge-case documents or copies of actual test PDFs.
- `reports/`: Accuracy reports generated by the evaluation scripts.
- `evaluate_extraction.py`: The main script to compare LangGraph extraction output against the `ground_truth/`.

## Methodology
1. **Ground Truth Creation**: Manually review a Mechanical Datasheet PDF. Do not rely on AI inferences. Map the document exactly to the 19 logical parameters. If a parameter is absent, set its value to `"MISSING"`. If it's ambiguous, set it to `"AMBIGUOUS"`. 
2. **Evaluation Execution**: The script parses `ground_truth/` and runs the document ingestion and extraction pipeline for the matching PDF in `fixtures/` or `example_pdfs/`. It compares the `ExtractionResult` after normalization against the ground truth.
3. **Normalization-Aware Matching**: The comparison does not strictly use string matching when units are involved, but respects normalized variants (e.g., `HOR` matches `HORIZONTAL`).

## Ground Truth Format
Ground truth JSON files must strictly align with the canonical `AnnexureRecord` representation. Example:
```json

  "tag_no": "A85-D-0001A",
  "description": "WATER/OIL SEPARATOR (WOSEP)",
  "ref_data_sheet": "MISSING",
  "design_code": "ASME SEC. VIII DIV. 1, 2021 ED. + U STAMP",
  "moc": "SA 516 Gr. 70N HIC",
  "qty": 2,
  "orientation": "HOR",
  "vessel_id_mm": 2400.0,
  "vessel_tl_tl_length_mm": 5800.0,
  "shell_min_thk_mm": 25.0,
  "head_min_thk_mm": 22.0,
  "head_type": "2:1 ELLIPSOIDAL",
  "nozzle_type": "Flanged",
  "impact_tested": "YES",
  "rt": "PER CODE",
  "pwht": "PER CODE / 32-SAMSS-004",
  "support_type": "Saddles",

}
```
